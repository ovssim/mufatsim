# Wormyard.Store Unboxing Simulator — Playable Beta

A static TF2-inspired unboxing game. 

## Included
- **Economy** and **Sandbox** modes, switchable without losing inventory.
- Browse **all numbered crates**.
- Crate purchasing, type-specific keys, keyless container example, refined/key wallet, and a repeatable beta stipend.


Backpack.tf API integration and live prices are included now. The API key will **never** be placed in client-side code. All metal and key prices here are arbitrary but as close as they can be to normal prices, although some items may be off. No real money, Steam items, or trading is involved.
